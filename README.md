# 🌱 Bintix Waste Analytics

Streamlit waste management analytics dashboard.

## Quick Start

```bash
git clone https://github.com/yourusername/bintix-waste-analytics.git
cd bintix-waste-analytics
pip install -r requirements.txt
streamlit run at.py
```

## Features
- Interactive maps (2D & 3D)
- CSV upload
- KPI metrics
- Heatmap visualization
- Community analytics

## CSV Format
Required: City, Community, Pincode, Latitude, Longitude
Metrics: Tonnage_Month, Trees_Saved_Month, CO2_Kgs_Averted_Month, etc.

See docs/DATA_FORMAT.md for details.
